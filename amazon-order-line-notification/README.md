# Amazon注文メール LINE自動通知

Amazon出品者向けの注文確定メールをGmailで検出し、Google Apps ScriptからLINE Messaging APIのプッシュメッセージで個人LINEへ通知する仕組みです。

Repair540のホームページ本体とは独立したGoogle Apps Script用コードです。

## 仕組み

1. GmailにAmazonの注文確定メールが届きます。
2. Gmailフィルターで対象メールに `Amazon注文通知` ラベルを付けます。
3. Google Apps Scriptの時間主導型トリガーが1分間隔で `checkAmazonOrderEmails` を実行します。
4. 以下の検索条件で、対象メールを探します。

```text
label:Amazon注文通知 newer_than:7d
```

5. 取得後、コード内でも差出人と件名を確認します。
6. メール本文から商品名、注文番号、出荷予定日を抽出できる場合は抽出します。
7. 1注文につき1件のLINE通知を送信します。
8. LINE送信に成功したメールのスレッドに `Amazon注文LINE通知済` ラベルを付けます。
9. メールごとのメッセージIDをスクリプトプロパティへ記録し、重複通知を抑止します。同じスレッドに複数の注文メールがあっても、各メールを1注文として1件ずつLINE通知します。

## 作成するGmailラベル

Gmailで以下の2つのラベルを作成してください。

```text
Amazon注文通知
Amazon注文LINE通知済
```

`Amazon注文LINE通知済` はコード側でも自動作成しますが、Gmail上で見える状態にしておきたい場合は事前に作っておいても構いません。

## Gmailラベルの作り方

1. Gmailを開きます。
2. 左側メニューの「もっと見る」を開きます。
3. 「新しいラベルを作成」をクリックします。
4. `Amazon注文通知` と入力して作成します。
5. 同じ手順で `Amazon注文LINE通知済` も作成します。

## Gmailフィルターの作り方

1. Gmail右上の歯車アイコンをクリックします。
2. 「すべての設定を表示」を開きます。
3. 「フィルタとブロック中のアドレス」を開きます。
4. 「新しいフィルタを作成」をクリックします。
5. 以下を入力します。

```text
From: seller-notification@amazon.co.jp
件名: 注文確定
```

6. 「フィルタを作成」をクリックします。
7. 実行内容として以下を選択します。

```text
ラベル「Amazon注文通知」を付ける
重要マークを付ける
迷惑メールにしない
受信トレイに残す
```

メールを自動的に既読にする設定は入れないでください。

## Google Apps Scriptへの登録方法

1. Google Apps Scriptを開きます。
2. 「新しいプロジェクト」を作成します。
3. プロジェクト名を分かりやすく `Amazon注文LINE通知` などに変更します。
4. 初期作成されている `コード.gs` の中身を削除します。
5. このフォルダの `Code.gs` の内容を貼り付けます。
6. 左側の「プロジェクトの設定」を開き、「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにします。
7. エディタに表示された `appsscript.json` の内容を、このフォルダの `appsscript.json` の内容に置き換えます。
8. 保存します。

## スクリプトプロパティの設定

アクセストークンやユーザーIDは、コード内へ直接書かないでください。

1. Apps Scriptの左側メニューから「プロジェクトの設定」を開きます。
2. 「スクリプト プロパティ」までスクロールします。
3. 「スクリプト プロパティを追加」をクリックします。
4. 以下の2つを追加します。

```text
LINE_CHANNEL_ACCESS_TOKEN
LINE_USER_ID
```

## LINE_CHANNEL_ACCESS_TOKENの取得場所

1. LINE Developers Consoleを開きます。
2. Messaging APIチャネルを作成、または既存のMessaging APIチャネルを開きます。
3. 「Messaging API設定」タブを開きます。
4. 「チャネルアクセストークン」を発行します。
5. 発行したトークンをApps Scriptのスクリプトプロパティ `LINE_CHANNEL_ACCESS_TOKEN` に登録します。

長期チャネルアクセストークンを使う場合も、外部に公開せず、Apps Scriptのスクリプトプロパティだけに保存してください。

## LINE_USER_IDの確認方法

個人ユーザーへプッシュメッセージを送るには、LINEの表示名やLINE IDではなく、Messaging API用のユーザーIDが必要です。

開発者本人のユーザーIDは、LINE Developers Consoleの対象チャネルの「チャネル基本設定」にある「あなたのユーザーID」で確認できます。

確認したユーザーIDをApps Scriptのスクリプトプロパティ `LINE_USER_ID` に登録してください。形式は通常 `U` で始まる長い文字列です。

## 友だち追加が必要です

LINE Messaging APIのプッシュメッセージを個人LINEで受け取るには、通知に使うLINE公式アカウントを通知先のLINEアカウントで友だち追加しておく必要があります。

友だち追加していない、またはブロックしている場合、API上は成功扱いになることがあっても、実際にはLINEに届かない場合があります。

## テスト送信

1. Apps Scriptエディタ上部の関数選択で `sendTestLineMessage` を選びます。
2. 「実行」をクリックします。
3. 初回実行時はGoogleの権限承認画面が出ます。
4. 承認後、個人LINEにテストメッセージが届くか確認します。
5. 届かない場合は「実行ログ」を確認してください。

## 初回実行時のGoogle権限承認

初回実行時には、Gmailの読み取りとラベル変更、外部サービスへの接続、トリガー作成に関する権限承認が必要です。

「このアプリはGoogleで確認されていません」と表示される場合があります。自分で作成したスクリプトであることを確認したうえで、「詳細」からプロジェクトへ進み、権限を許可してください。

## 本番トリガーの作成

テスト送信が成功したら、1分間隔のトリガーを作成します。

1. Apps Scriptエディタ上部の関数選択で `createMinuteTrigger` を選びます。
2. 「実行」をクリックします。
3. 実行ログに `checkAmazonOrderEmails を1分間隔で実行するトリガーを作成しました。` と表示されれば完了です。

`createMinuteTrigger` は既存の同名トリガーを削除してから作成するため、同じトリガーが重複作成されません。

## トリガーの削除方法

不要になった場合は、Apps Scriptで `deleteAmazonOrderTriggers` を実行してください。

または、Apps Script左側メニューの「トリガー」から `checkAmazonOrderEmails` のトリガーを手動で削除できます。

## LINE通知の内容

通知例です。

```text
📦 Amazonで新しい注文が入りました

商品：
HANRO（ハンロ）COTTON SEAMLESS キャミソール

注文番号：
64-8NL1-95AX

出荷予定日：
2026/07/24まで

受信日時：
2026/07/18 13:33

Gmailを確認して、注文内容と出荷期限を確認してください。

https://sellercentral.amazon.co.jp/
```

商品名、注文番号、出荷予定日が抽出できない場合は、件名と受信日時を中心に通知します。メール本文全体はLINEへ送りません。

## 正常に通知できない場合の確認事項

以下を確認してください。

```text
Gmailに Amazon注文通知 ラベルが付いているか
差出人が seller-notification@amazon.co.jp か
件名に 注文確定 が含まれているか
LINE_CHANNEL_ACCESS_TOKEN が正しいか
LINE_USER_ID が正しいか
通知用LINE公式アカウントを友だち追加しているか
LINE公式アカウントをブロックしていないか
Apps Scriptの実行ログにエラーが出ていないか
Apps Scriptのトリガーが有効になっているか
```

## 安全性

このコードでは以下を守ります。

```text
秘密情報をソースコードに書かない
アクセストークンをログへ出力しない
メール本文全体をLINEへ送らない
LINE送信成功時だけ通知済みラベルを付ける
エラーが発生しても可能な範囲でほかのメール処理を続ける
LockServiceで同時実行を防ぐ
一度の実行で処理する件数を最大10件に制限する
```

## 補足

Apps Script標準のGmailラベル操作は基本的にスレッド単位です。そのため、`Amazon注文LINE通知済` ラベルはGmail上での目印として使用し、検索対象からは除外しません。メールごとのメッセージIDをスクリプトプロパティへ保存して重複通知を抑止するため、同じスレッドに後から別の注文メールが届いた場合も、その注文だけを新たに通知できます。
